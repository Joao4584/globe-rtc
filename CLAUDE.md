# CLAUDE.md

## Startup rule

Always read `.claude/docs/project-overview.md`,
`.claude/docs/product-vision.md`, and `.claude/docs/dev-workflow.md` at
the start of each session and use them as primary context for the
project's purpose, direction, and how to run it.

Keep `.claude/docs/` up to date: whenever the user states a preference,
a workflow detail, or an idea about the project that isn't obvious from
the code, add or update a doc under `.claude/docs/` (in English) so
later sessions don't have to ask again.
